# PESKOV Smart Planner 📋

PWA-планировщик задач с голосовым вводом.

## Функции
- ✅ Добавление, редактирование, удаление задач
- 🎙 Голосовой ввод (Web Speech API, Chrome/Android)
- 📅 Полоса дат с навигацией
- 🌐 3 языка: Русский, English, O'zbek
- 📊 Статистика по задачам
- 📤 Экспорт JSON / CSV
- 📲 PWA — установка на телефон

## Установка на GitHub Pages

1. Создать репозиторий `peskov-planner` (Public)
2. Загрузить все файлы
3. Settings → Pages → Deploy from branch `main` / `(root)`
4. Через 2 минуты: `https://USERNAME.github.io/peskov-planner/`

## Файлы
- `index.html` — главное приложение
- `manifest.json` — PWA-паспорт
- `sw.js` — Service Worker (офлайн)
- `icon-192.png` — иконка 192×192
- `icon-512.png` — иконка 512×512
- `apple-touch-icon.png` — иконка для iOS
