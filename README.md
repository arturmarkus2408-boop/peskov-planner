## 🌟 Возможности

- ✅ **Голосовое создание задач** — скажите фразу, AI парсит дату, время, приоритет, напоминание
- 📝 **Заметки с офлайн-вложениями** — фото, PDF, аудио, ссылки. Открываются без интернета
- 🎙 **Диктофон с расшифровкой** — аудио + текст одновременно
- 🔁 **Повторяющиеся задачи** — ежедневно / по будням / еженедельно / ежемесячно
- ⏱ **Фокус-таймер (Помодоро)** — 25 мин работы / 5 мин отдыха
- 🏷 **Настраиваемые теги** — любые названия и цвета
- ☁️ **Облачная синхронизация** между устройствами с **шифрованием AES-256**
- 📊 **Статистика** — графики, streak-счётчик, тепловая карта активности
- 🌐 **3 языка**: RU / EN / UZ
- 🎨 **3 темы**: Тёмная / Светлая / Изумрудная
- 🔔 **Push-уведомления** с кнопками «Выполнено» и «+10 минут»
- 📱 **PWA** — устанавливается на телефон как обычное приложение

## 🚀 Развёртывание для многих пользователей (БЕСПЛАТНО)

### Способ 1: GitHub Pages (рекомендуется)

**Зачем:** бесплатный хостинг от Microsoft, HTTPS, до 100 ГБ трафика в месяц. Идеально для PWA.

1. Зайдите на https://github.com и зарегистрируйтесь (бесплатно)
2. Нажмите **New repository** (зелёная кнопка)
3. Имя репозитория: `peskov-planner` → **Public** → **Create**
4. Нажмите **uploading an existing file**
5. Перетащите все 4 файла (`index.html`, `sw.js`, `manifest.json`, иконки)
6. Внизу **Commit changes**
7. Откройте **Settings** репозитория → слева **Pages**
8. В разделе **Branch** выберите `main` → **Save**
9. Через 1-2 минуты приложение доступно по адресу: `https://ваш_логин.github.io/peskov-planner/`

**Готово!** Делитесь ссылкой с друзьями — у каждого свои данные.

### Способ 2: Netlify (тоже бесплатно)

1. https://app.netlify.com → **Sign up** (бесплатно)
2. **Add new site** → **Deploy manually**
3. Перетащите папку с файлами в окно
4. Получите URL вида `https://random-name.netlify.app`
5. В настройках можно изменить домен на свой

### Способ 3: Cloudflare Pages

1. https://pages.cloudflare.com → **Sign up**
2. **Create application** → **Upload assets**
3. Загрузите файлы → готово

**Все три варианта дают:**
- ✅ Бесплатный HTTPS (обязателен для PWA)
- ✅ Глобальный CDN (быстро открывается из любой страны)
- ✅ Безлимит на пользователей

## 📲 Установка на телефон

После размещения файлов на хостинге:

### Android (Chrome):
1. Откройте URL в Chrome
2. Меню (⋮) → **Установить приложение** (или «Добавить на главный экран»)
3. Подтвердите — иконка появится на рабочем столе
4. Открывается как обычное приложение, без браузера

### iOS (Safari):
1. Откройте URL в Safari
2. Кнопка **Поделиться** (квадрат со стрелкой вверх)
3. **На экран «Домой»** → Добавить

## ☁️ Облачная синхронизация (между устройствами)

### Зачем
Чтобы данные с телефона видеть на ноутбуке (и наоборот).

### Безопасность
Данные шифруются **AES-256** на вашем устройстве перед отправкой. JSONBin.io (бесплатный облачный сервис) хранит только зашифрованный поток. Без пароля прочитать невозможно.

### Шаг 1: первое устройство (телефон)
1. Откройте приложение → **Настройки ⚙️**
2. В блоке «Облачная синхронизация» нажмите **📤 Сохранить**
3. Появится окно — **придумайте сложный пароль** (запомните или запишите!)
4. Получите **Sync ID** (длинный код) — нажмите на него для копирования

### Шаг 2: второе устройство (ноутбук)
1. Откройте то же приложение в браузере ноутбука
2. **Настройки** → блок «Облачная синхронизация» → **🔗 Подключить**
3. Вставьте Sync ID → OK
4. Введите **тот же пароль**
5. Нажмите **📥 Загрузить** — все данные появятся

### Регулярно
- После изменений на телефоне → нажмите **📤 Сохранить**
- На ноутбуке → нажмите **📥 Загрузить**

## 🔔 Как работают напоминания

В установленное время:
1. Прозвучит **звуковой сигнал**
2. Появится **уведомление** с кнопками:
   - **✓ Выполнено** — задача отмечается выполненной
   - **💤 +10 мин** — отложить на 10 минут
3. Кнопки работают **прямо из шторки уведомлений**

### Для надёжности:
1. **Установите PWA на телефон** (см. выше)
2. При первом запуске **разрешите уведомления**
3. Не закрывайте приложение полностью (свайп вверх из недавних) — оставляйте в фоне

### Ограничение
В чистом PWA без серверной части напоминания работают:
- ✅ Гарантированно, если PWA открыта или была недавно закрыта (5-15 мин)
- ✅ При следующем открытии — все пропущенные срабатывают
- ⚠️ Не гарантировано через 24 часа после полного закрытия

Это ограничение всех PWA без серверной части. Для 100% надёжности нужен бэкенд с Web Push (~$5/мес на VPS).

## 🛠 Технические детали

- **Один файл `index.html`** — всё внутри: HTML + CSS + JS
- **Без зависимостей**, кроме CryptoJS (CDN) для шифрования синхронизации
- **IndexedDB** для хранения файлов (фото, PDF) — без жёсткого лимита, как нативное приложение
- **localStorage** для задач, заметок, тегов
- **Service Worker** для офлайн-работы и push-уведомлений
- **Web Speech API** для голосового ввода (поддерживается Chrome, Edge, Safari)

### Браузеры
- ✅ Chrome / Edge (Android, Windows, macOS, Linux) — полная поддержка
- ✅ Safari (iOS, macOS) — работает с ограничениями push-уведомлений
- ⚠️ Firefox — Web Speech API не работает
